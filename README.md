# SVF-1051 – data til seminarene

Datasett til undervisningen i SVF-1051.

| Fil | Innhold |
|---|---|
| `data/kommuner_2025.csv` | Én rad per kommune: folketall, branner, utrykninger, brannvern og trafikkulykker i 2025 |
| `data/trafikk_aar.csv` | Drepte og hardt skadde i veitrafikken per år, 1946–2025 |
| `data/trafikk_grupper.csv` | Drepte og skadde i 2025 etter kjønn, alder, trafikantgruppe og skadegrad |
| `data/hent_data.R` | Skriptet som henter og rydder dataene |

Kilde: Statistisk sentralbyrå (SSB), Statistikkbanken, tabell 07459, 09000, 12043, 12044 og 12058.
